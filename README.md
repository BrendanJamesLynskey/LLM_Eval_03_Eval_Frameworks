# LLM_Eval_03_Eval_Frameworks

A practical survey of the major LLM evaluation frameworks. Covers Inspect AI (UK AISI), Braintrust, Phoenix (Arize), Langfuse, OpenAI Evals, and deepeval, with detailed architectural notes, code examples, integration patterns, and a decision matrix for choosing the right tool based on deployment model, observability needs, and eval type.

**Live site:** https://brendanjameslynskey.github.io/LLM_Eval_03_Eval_Frameworks/

Part of the [LLM Evaluations sub-hub](https://github.com/BrendanJamesLynskey/LLM_Hub_Evaluations)
